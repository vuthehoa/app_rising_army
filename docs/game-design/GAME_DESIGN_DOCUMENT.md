# Game Design Document (MVP)

Tầm nhìn: quản lý doanh trại và quân đội thời cổ đại, đánh chiến dịch chống quân phiệt. Sản phẩm độc lập,
không dùng tài sản/tên riêng của game tham khảo.

Vòng lặp: nhận doanh trại → sản xuất tài nguyên (qua ngày) → xây/nâng cấp, nghiên cứu → tuyển & huấn luyện
→ chọn đội hình + chiến thuật → đánh ải → thương vong/thưởng → mở ải kế → lưu.

Thẩm mỹ: nền tối, xanh rêu, sắt, vàng đồng; tiêu đề serif (Georgia); icon vector, không emoji.
Mọi nút bị khóa đều hiện lý do (thiếu tài nguyên, cần cấp công trình...).
